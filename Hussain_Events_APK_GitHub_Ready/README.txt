HUSSAIN EVENTS - LIGHTWEIGHT ANDROID APK PROJECT

Purpose:
This is a lightweight Android WebView wrapper around the Hussain Events Simple Version.
It is designed to avoid the need for a large native Android application.

Important:
- This ZIP is an Android project, NOT a compiled APK.
- A compatible Android SDK/build environment is still required to compile the APK.
- The current app stores demo data locally on the device.
- The PIN in the web app is demo-only (123456).
- For production, connect the app to Firebase/secure authentication.

For a Windows 7 + 4GB RAM machine, modern Android Studio is not recommended.
A separate newer PC or cloud build service may be needed for the final APK.
